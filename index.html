What "unbreakable" actually means here

This isn't about being "hard for an AI." A correctly used OTP has zero exploitable structure — every possible plaintext of the same length is an equally valid explanation of any given ciphertext, so there is nothing for any attacker (human, classical computer, or AI) to compute their way through. That guarantee depends entirely on three operational rules, which no software can enforce for you once the key leaves this page: (1) the key is truly random (this page uses crypto.getRandomValues, a CSPRNG — never a plain Math.random()), (2) the key is never reused for another message, and (3) the key stays as secret as the message itself and is discarded after one use. This tool is for learning and testing the algorithm — treat it as a demo, not a channel for exchanging real secrets over an untrusted machine.
